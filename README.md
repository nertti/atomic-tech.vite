# Atomic Studio

Многостраничный сайт на Vite 8 с HTML-шаблонами Handlebars и jQuery.

## Запуск

Используйте Node.js 24 LTS. Минимальные поддерживаемые версии: Node.js 20.19 или 22.12.
Требования Vite: https://vite.dev/guide/.

```sh
npm ci
npm run dev
```

Адрес сервера появится в терминале (обычно http://localhost:5173).

## Сборка

```sh
npm run build
npm run preview
```

Готовый сайт находится в `docs/`. Размещайте содержимое этой папки целиком,
включая `img/`, `css/`, `js/` и видео. Относительные пути позволяют размещать
сборку как в корне домена, так и в подпапке.

`preview` предназначен для локальной проверки сборки. Страницу `404.html`
нужно назначить страницей ошибки в настройках production-сервера.

## Структура

- `index.html`, `service.html`, `projects.html`, `detail.html`, `404.html`, `policy.html`: страницы сайта.
- `src/partials/`: общие шапка, подвал и мобильное меню; подключаются через `{{> name }}`.
- `src/js/main.js`: общая точка входа, подключение CSS и jQuery-плагинов.
- `src/js/components/`: меню, фильтр, слайдеры и бегущие строки.
- `src/css/main.css`: порядок подключения стилей.
- `public/`: статические изображения, favicon и видео, копируемые без переименования.

В исходных HTML и CSS используйте пути `/img/...` и `/mockupBanner.MP4`
без префикса `public/`. Vite преобразует их при сборке.
Изменения `.hbs` автоматически перезагружают страницы на dev-сервере.

Для новой страницы добавьте HTML-файл в корень проекта, подключите
`/src/js/main.js` как модуль и добавьте страницу в `build.rolldownOptions.input`
в `vite.config.js`.

## Страница услуги

Страница `service.html` («Веб-разработка под ключ») повторяет десктопные секции
под экраном «1936» и соседнюю мобильную колонку от «1» в «Атом (v4).fig».
Тексты карточек, этапов и FAQ находятся в `src/data/service-content.js`,
стили — в `src/css/service.css`, интерактивность — в `src/pages/service.js`.
На мобильных четыре карточки цикла разработки листаются горизонтально,
шесть сценариев идут одной колонкой. Этапы и FAQ можно раскрывать с клавиатуры.
При прокрутке активным становится этап, ближайший к центру видимой области
под шапкой: выделяются его заголовок, номер и точка на линии, раскрывается описание.
В каждой группе одновременно может быть открыт только один пункт; FAQ изначально
полностью закрыт. Переход на страницу подключён
из десктопного и мобильного меню и каталога главной.
Тексты `service-definition` и `service-result` плавно появляются при входе в экран.
При включённом уменьшении движения текст показывается сразу.
Иллюстрации цикла разработки используют SVG с внутренними тенями и отдельные
стеклянные слои с `backdrop-filter`; их геометрия из локального макета находится
в `src/data/service-cycle-art.js`.
Форма использует существующее поведение сайта: отправка на сервер пока не подключена.

## Видео на главной

Главная обновлена по файлу «Атом (v2).fig»: основа — десктопные секции под
Star 10 и соседние мобильные макеты. Изменения этой версии находятся в
`src/css/home-v2.css`, разметка — в `src/partials/home-*.hbs`.
Состояния кнопок при наведении обновлены по блоку «Ховеры» из «Атом (v4).fig»:
кнопки в шапке и первом экране получают радиальный градиент с бирюзовым
свечением снизу по `Frame 2087327147` (`584:243`); контурные кнопки, их стрелки и текст кнопки
формы используют цвет `#7ecaca`. Эффекты включены только на десктопе (от 901 px)
с точным указателем и поддержкой наведения; на мобильных и сенсорных устройствах
кнопки сохраняют обычное состояние. Выделение фокуса с клавиатуры доступно везде.
Мобильное меню повторяет три состояния под Star 12 в «Атом (v4).fig»:
сначала показаны общие разделы сайта. «Услуги» раскрывает пять направлений,
а каждое направление — описание и список услуг внутри того же меню.
Плюс меняется на минус, стрелка раскрытого направления поворачивается вниз.
Кнопка меню закрывает его из любого состояния.
Закрыть меню также можно нажатием на фон или Escape; фон страницы не прокручивается.
На мобильных кейсы показаны списком, а карточки запросов и преимуществ
можно прокручивать по горизонтали. На десктопе три кейса переключаются вертикально:
между карточками 16 px, снизу видны первые 32 px следующего кейса.
Кейсы листаются тачпадом и колесом мыши: один жест переключает одну карточку,
а на начале и конце ленты новый жест продолжает прокрутку страницы.
При пролистывании `home-why__cards` активная карточка преимуществ получает
то же оформление, что при наведении на десктопе. Подсветка обновляется при прокрутке.

В мобильном каталоге услуг пять карточек идут одной колонкой с промежутками 12 px
и прокручиваются вместе со страницей. На десктопе вертикальная прокрутка удерживает заголовок и карточки под шапкой и
пролистывает их по горизонтали. После последней карточки страница продолжает
движение; при возврате вверх карточки проходят в обратном порядке. Свайпы,
перетаскивание и клавиатура синхронизированы с этой прокруткой. На низком экране
заголовок сначала уходит вверх, затем карточки закрепляются целиком под шапкой
и пролистываются горизонтально. Если по высоте не помещается уже сама карточка,
остаётся обычная прокрутка и горизонтальный свайп.
После контролов до следующего раздела сохраняется отступ 60 px на всём участке закрепления.

Первый экран использует `public/mockupBanner.MP4`: видео запускается без звука,
зациклено и воспроизводится внутри страницы на телефонах. Кадрирование сохраняет
центр анимации, а высота баннера уменьшается на узких экранах. На широких экранах
композиция ограничена контейнером 1440 px, а края заполнены размытой копией видео.
В переходном диапазоне 700–1100 px используется блок «1950»: видео заполняет первый экран
высотой 630 px, а текст и кнопка стоят по центру на полупрозрачной плашке.
Дополнительное видео создаётся только для широкого экрана; вне первого экрана
воспроизведение приостанавливается. Изображение
`home-hero-v2.png` служит обложкой до загрузки видео. При включённом уменьшении
движения в системных настройках воспроизведение приостанавливается.

В `src/data/home-content.js` объект `homeVideo` управляет отдельным блоком перед отзывами.
Пока `src` пустой, отображается заглушка из макета. Для подключения MP4
поместите файл в `public/video/` и задайте `src: '/video/atomic.mp4'`.
Необязательные поля: `poster` для обложки и `captions` для русских субтитров VTT.
Плеер использует стандартные элементы управления, не запускается автоматически
и не загружает видео до воспроизведения.

Форма заявки пока не подключена к серверу: она проверяет обязательные поля
и оба согласия, сохраняет введённые данные и сообщает об отсутствии отправки.

Ленты отзывов можно перетаскивать мышью, листать свайпами и стрелками клавиатуры.
Автопрокрутка останавливается при наведении, фокусе и ручной прокрутке;
при включённом уменьшении движения отзывы прокручиваются только вручную.

Карточки блога целиком являются ссылками. Адрес каждой статьи задаётся полем
`href` в массиве `blogArticles` в `src/data/home-content.js`; пока используются
заглушки `#blog`. Перетаскивание слайдера не открывает ссылку.
